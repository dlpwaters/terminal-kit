# Terminal Kit inventory

Terminal Kit's `headless` profile is the required CLI/editor/agent setup. `workstation` adds the graphical terminal and font. Authentication remains the user's step after installation. These defaults are part of the intended profile; they are not optional merely because providers or graphical packages vary by platform.

| Category | Upstream examples inspected | Decision | Dependencies and boundary |
| --- | --- | --- | --- |
| Shell and core commands | Omarchy `default/bash/`, aliases, completions, inputrc | Include/adapt | Bash, Bash completion, Git, GitHub CLI, tmux, ripgrep, fd, bat, btop, jq, curl, tar/unzip, build tools. Adapt reusable shell behavior and condition hooks on installed commands. |
| Search, navigation, listing and prompt | fzf, ripgrep, fd, bat, eza, zoxide, Starship | Required in both profiles | fzf previews use bat; zoxide and Starship initialization is conditional on the command. Plain `ls`, `find`, and shell behavior remain available as fallbacks. |
| Git and container TUIs | lazygit, lazydocker | Required in both profiles | Git is required. LazyDocker is installed as a client; Docker Engine/service stays a separate opt-in and is not started or granted group access by this profile. |
| System monitor and structured data | btop, jq | Required in both profiles | Installed from supported distribution package repositories. |
| Runtime/tool management | mise and its Node runtime | Required in both profiles | mise, Node.js and npm support the agent clients. Versions are pinned in the tool manifest. Do not copy Omarchy's global trust or upgrade policies. |
| Neovim and LazyVim | Neovim, LazyVim Starter, Omarchy's separate `omarchy-nvim` recipe/cache | Required in both profiles | Install the Terminal Kit pinned Neovim release and adapted LazyVim config. Use the official Aug 2026 package artifact/lock as provenance; copy selected config and lock data, not the full generated plugin cache or `/etc/skel` setup. Preserve existing user config through Terminal Kit's managed entrypoint/backup behavior. Package build dependencies and embedded per-plugin licenses are in the upstream manifest. |
| Coding-agent CLIs | Pi, Hermes, OpenCode | Required in both profiles | Install all three pinned clients. Installation does not authenticate, inspect credentials, or invoke an agent. Account/provider setup is a separate user action and may remain pending. Pi requires the pinned compatible Node/npm runtime. Hermes uses its official pinned staged installer with browser, computer-use, setup, gateway and skills stages excluded. |
| Terminal emulator | Ghostty; Omarchy also configures Foot, Kitty and Alacritty | Workstation default | Use supported native sources: Ghostty's official macOS app, Arch package, Homebrew cask, or Ubuntu 26.04+ package. There is no native Windows build, and many Linux distributions lack a supported native package in this installer. Report that platform gap; don't add a third-party repository or silently substitute another GUI terminal. Headless omits the emulator. |
| Font | JetBrainsMono Nerd Font | Workstation default | Download the pinned official Nerd Fonts archive and retain its OFL notice. Install into the Linux/macOS user font directory; WSL font setup must target the Windows host explicitly through `windows/Install-Font.ps1`. Headless omits fonts. |
| Python runtime | mise Python; Hermes-managed uv | Optional `--with python` | Adds isolated mise Python. Hermes manages its own supported uv/Python environment through its official installer; the kit does not install a second global uv tool. |
| Native extra utilities | tealdeer, ncdu, tree | Optional (`--with extras`) | Installed through apt/dnf/pacman/Homebrew package mappings. They are not required by the baseline. |
| Tree-sitter CLI compatibility | Tree-sitter CLI 0.26.1 source | Optional fallback (`--with treesitter-build`) | Needed where the official CLI binary requires a newer glibc than the host. The source build uses pinned isolated mise Rust and native libclang headers, and does not update core system libraries. Debian 12/glibc 2.36 cannot run upstream 0.27 or 0.26.1 binaries requiring glibc 2.39. |
| Other candidate CLIs | fastfetch, Yazi, dust | Omit for now | No implemented selectable install path in the current baseline. |
| Agent/desktop extras | Herdr; Omarchy agent skills, desktop agent dispatch and auto-approval aliases | Omit | Herdr is not included because its upstream source/release and installation path have not been verified for this kit. Do not copy Omarchy's skill directories, profile wiring, theme runtime, `omarchy-agent` task dispatch, or aliases that launch agents in auto/approval-bypass modes. |
| Bash helpers: compression and sessions | `compress`, `decompress`, tmux layout/session helpers | Adapt | Compression uses the platform `tar`; session/layout commands are explicit and use Terminal Kit's own layouts. Shell startup must not create or attach to a session implicitly. |
| Bash helpers: remote file transfer | `sff`, rsync watch/list/stop functions, SSH reconnect/port forwarding | Omit for now | These depend on `scp`, `rsync`, `inotifywait`, SSH options or background process conventions. The rsync watcher can repeatedly mutate a destination, so it needs separate user-visible behavior before inclusion. |
| Bash helper: Git worktrees | `ga BRANCH` | Adapt | Creates a new branch/worktree beside the current repository and enters it. Requires a valid, unused branch and destination. No automatic trust changes, forced removal, or branch deletion helper is included. |
| Disk and image helpers | `iso2sd`, `format-drive` | Omit | These use privileged `dd`, `wipefs`, partitioning and filesystem tools, and can erase a selected device. Terminal Kit does not install or expose them. |
| Desktop/system integration | Hyprland, Quickshell, systemd user services, native messaging hosts, crash capture, Omarchy package/provisioning commands | Omit | These depend on Omarchy's desktop and system policy and are outside the portable terminal environment. |
| Other GUI/system packages | Browser, office, media, printer and hardware utilities from the Omarchy base package list | Omit | Outside scope; none is pulled as a transitive dependency of the terminal profiles. |

The authoritative upstream pins, package/artifact checksums, and license notices are in [`../manifests/upstreams.json`](../manifests/upstreams.json) and [`../licenses/third-party/`](../licenses/third-party/). Profile selection is not the same as end-to-end acceptance: see [support status](SUPPORT.md) for platform-specific verification.
